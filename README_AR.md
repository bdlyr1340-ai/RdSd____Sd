# 🤖 بوت التحكم بالمتصفح | Browser-Control Telegram Bot

بوت تيليجرام احترافي يُشغّل متصفّحاً (Chromium) عن بُعد، وتتحكّم به أنت
من تلجرام. كل ضغطة زر تُنفّذ خطوة فعلية في المتصفح، وتعيد لك *لقطة شاشة*
لما حدث. عند انتهاء الجلسة تستلم *سكربت Playwright جاهز* يعيد كل ما فعلته.

---

## ✨ الأزرار

| الزر | الوظيفة |
|------|---------|
| 🌐 افتح رابط | يطلب منك رابطاً ويفتحه |
| 📸 لقطة شاشة | يلتقط الشاشة الحالية |
| ⬅️ رجوع | الرجوع للصفحة السابقة |
| 🔄 تحديث | إعادة تحميل الصفحة |
| ↩️ Enter | إرسال مفتاح Enter |
| ⌨️ كتابة نص | يطلب نصاً ويكتبه في الحقل المُركَّز |
| ❌ حذف النص | تحديد كل النص (Ctrl+A) ثم حذفه |
| ⬆️ صعود بسيط | تمرير 300px للأعلى |
| ⬇️ نزول بسيط | تمرير 300px للأسفل |
| ⏫ صعود نهاية | إلى أعلى الصفحة |
| ⏬ نزول نهاية | إلى أسفل الصفحة |
| 🔢 شبكة الموس | يلتقط الشاشة ويرسم عليها مربعات مرقّمة — أرسل رقم المربع للضغط |
| ⚙️ إعدادات الشبكة | اختيار أبعاد الشبكة (حد أقصى 2000 مربع) |
| 🔍 بحث + ضغط | ابحث عن نص في الصفحة واضغط عليه |
| 🔎 بحث + ضغط + مسح | ابحث + اضغط + امسح محتوى الحقل |
| 🛡️ كود التحقق | يكتشف أرقام التحقق على الصفحة (4–8 أرقام بجوار "code/كود/تحقق") |
| 🕒 تسجيل الوقت | يضع علامة زمنية في سجل الجلسة |
| 💾 حفظ وإنهاء الجلسة | يولّد سكربت Python + تقرير Markdown + JSON |

## 🚀 طريقة التشغيل

### 1) متطلبات النظام
- Python 3.11+
- متصفح Chromium (يُثبَّت تلقائياً عبر Playwright)
- نظام Linux / macOS / Windows

### 2) إنشاء بوت تلجرام
1. افتح [@BotFather](https://t.me/BotFather)
2. أرسل `/newbot` واتّبع التعليمات
3. انسخ التوكن الذي يصلك

### 3) التشغيل المحلي
```bash
git clone <repo>  # أو فك الضغط
cd browser-control-bot

python -m venv .venv
source .venv/bin/activate          # على Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install --with-deps chromium

cp .env.example .env
# عدّل .env وضع BOT_TOKEN

# للتشغيل:
python -m bot.main
```

### 4) النشر على Railway
1. ارفع المستودع إلى GitHub.
2. أنشئ مشروعاً جديداً على Railway واربطه بالمستودع.
3. أضف متغيّر البيئة `BOT_TOKEN` في Variables.
4. (اختياري) أضف `ADMIN_IDS` لتقييد البوت على أيدي محدّدة.
5. Railway يقرأ الـ `Dockerfile` ويبني تلقائياً — لا تحتاج خطوات إضافية.

### 5) التشغيل عبر Docker
```bash
docker build -t browser-bot .
docker run -e BOT_TOKEN="123:abc" -e ADMIN_IDS="1234567" browser-bot
```

## 🎮 سير العمل

1. أرسل `/start` للبوت → اضغط *🚀 بدء جلسة جديدة*.
2. يُشغَّل لك متصفّح ولوحة تحكّم (الأزرار في الجدول أعلاه).
3. كل ضغطة زر = خطوة في المتصفح + لقطة شاشة فورية.
4. لاستخدام شبكة الموس:
   - اختر إعداداً من *⚙️ إعدادات الشبكة*.
   - اضغط *🔢 شبكة الموس* → ستصلك لقطة عليها مربعات مرقّمة.
   - أرسل رقم المربع (مثل `123`) → البوت يضغط في مركز ذلك المربع.
5. اضغط *💾 حفظ وإنهاء الجلسة* فيرسل لك:
   - `session_<id>_<ts>.py` — سكربت Playwright جاهز للتشغيل.
   - `session_<id>_<ts>.md` — تقرير مفصّل بالخطوات.
   - `session_<id>_<ts>.json` — البيانات الخام لإعادة الاستخدام.

## 🔐 الحماية

- إذا تركت `ADMIN_IDS` فارغاً، أيّ مستخدم يصل إلى البوت يستطيع
  استخدامه. هذا غير آمن في الإنتاج — ضع IDs محدّدة دائماً.
- المتصفح يعمل في نمط **headless** افتراضياً. لتعطيله محلياً (لرؤيته):
  ضع `HEADLESS=0` في `.env`.

---

## 🧠 ملاحظات تقنية

- كل مستخدم يحصل على *سياق متصفح معزول* خاص به.
- لقطة شاشة *Viewport* (وليس الصفحة الكاملة) — هذا متعمَّد لأن الشبكة
  المرقّمة تعتمد على إحداثيات الشاشة الفعلية.
- كشف كود التحقق يعتمد على نص الصفحة (DOM) — يبحث عن أرقام
  4–8 خانات بجوار كلمات (`code`, `verification`, `كود`, `تحقق`).
- السكربت المُولَّد يُعيد الإجراءات الفعلية (إحداثيات النقر، كتابة النصوص،
  تمرير الصفحة). لقطات الشاشة لا تُعاد توليدها لأن الهدف هو *الأتمتة*،
  وليس النسخ الحرفي للجلسة.

## ❓ مشاكل شائعة

| المشكلة | الحل |
|---------|------|
| `Missing env vars: BOT_TOKEN` | ضع `BOT_TOKEN` في `.env` أو في متغيّرات النظام |
| لا تظهر لقطات الشاشة | تحقّق أن `playwright install chromium` نُفّذ |
| الخطّ في الشبكة يبدو صغيراً | الإعدادات الأكبر (40×40+) ستضيق الأرقام تلقائياً |
| الزر *Find + Click* لا يجد العنصر | جرّب نصاً أكثر تحديداً، أو استخدم *🔢 شبكة الموس* |
| الجلسة بطيئة | ضع `HEADLESS=1`، وتأكّد أنّ الذاكرة كافية (≥1GB) |
