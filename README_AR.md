# 🤖 بوت التحكم بالمتصفح | Browser-Control Telegram Bot

بوت تيليجرام احترافي يُشغّل متصفّحاً عن بُعد، وأنت تتحكّم به من تلجرام. كل
ضغطة زر تُنفّذ خطوة فعلية وتعيد لقطة شاشة. عند انتهاء الجلسة تستلم *سكربت
Python جاهز* يُعيد كل ما فعلته.

🦊 **Camoufox** (Firefox مكافح للكشف) كمتصفح أساسي.
⌨️ **محاكاة كتابة بشرية** فعلية — توقيت متغيّر، توقّفات تفكير، وأخطاء وتصحيح اختياري.
🌍 **ملفات دول** كاملة (وقت + لغة + GPS) مع أو بدون بروكسي.

---

## 🦊 لماذا Camoufox؟

في Chromium العادي (Playwright)، كل ضغطة مفتاح صناعية تحمل خاصية
`isTrusted: false` — مواقع كشف البوتات تستطيع تمييزها فوراً. **Camoufox**
هو Firefox مُعدَّل يجعل هذه الأحداث `isTrusted: true` تماماً مثل المستخدم
الحقيقي، ويُخفي خصائص JS الكاشفة (`navigator.webdriver` وغيرها).

البوت يكتشفه تلقائياً عند بدء التشغيل ويستخدمه إن كان مثبّتاً. لإجباره
استخدم متغيّر البيئة `BROWSER_ENGINE=camoufox`.

---

## ⌨️ محاكاة الكتابة البشرية

ليست `keyboard.type(text)` العادية. كل حرف يُرسل بضغطة منفردة بتوقيت
ديناميكي:
- توزيع لوغاريتمي طبيعي للتأخير بين الحروف
- توقّفات أطول قبل علامات الترقيم والمسافات
- توقّفات «تفكير» عشوائية (~3.5%، 0.3-0.9 ثانية)
- ضربات سريعة في بداية الكلمات (burst)
- توقّف توجّه قبل أوّل حرف، توقّف استقرار بعد آخر حرف
- (اختياري) أخطاء كتابة على المفاتيح المجاورة + تصحيح بـ Backspace

الأخطاء يتم تعطيلها تلقائياً للنصوص الحساسة (إيميلات، روابط، أرقام صرف).

## 🌍 ملفات الدول

8 دول جاهزة: 🇮🇶 العراق · 🇪🇬 مصر · 🇸🇦 السعودية · 🇦🇪 الإمارات
🇺🇸 أمريكا · 🇬🇧 بريطانيا · 🇩🇪 ألمانيا · 🇹🇷 تركيا

كل دولة تُطبَّق على المتصفح بكامل ملفها:
- **TimeZone** — `Date()` و `Intl` JavaScript يعطون توقيت الدولة
- **Locale** — `navigator.language` مطابق
- **Accept-Language** — رأس HTTP صحيح
- **Geolocation** — إحداثيات `navigator.geolocation` تشير لعاصمة الدولة

⚪ بجانب الدولة = ملف فقط (الـ IP الحقيقي).
بدون ⚪ = ملف الدولة + بروكسي → IP من الدولة فعلياً.

### تفعيل بروكسي لدولة:
```env
PROXY_IQ=http://user:pass@iraq-proxy.example.com:8080
PROXY_US=socks5://us-proxy.com:1080
```

من أين تحصل على بروكسيات:
- **مدفوع موصى به:** BrightData / Smartproxy / Oxylabs / Soax (Residential)
- **VPS خاص:** استأجر VPS رخيص من DigitalOcean/Vultr/Hetzner في الدولة
  المطلوبة، نصّب SOCKS5 (`dante-server`)، ضع الرابط في `.env`.

## 🚀 طريقة التشغيل

### التشغيل المحلي
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Camoufox (الموصى به):
python -m camoufox fetch

# Playwright Chromium (احتياطي):
playwright install --with-deps chromium

cp .env.example .env
# عدّل .env وضع BOT_TOKEN

python -m bot.main
```

### Docker / Railway
الـ Dockerfile يثبّت Camoufox و Chromium تلقائياً. على Railway اربط
المستودع وأضف `BOT_TOKEN` في Variables.

```bash
docker build -t browser-bot .
docker run \
  -e BOT_TOKEN="123:abc" \
  -e BROWSER_ENGINE=auto \
  -e ADMIN_IDS="1234567" \
  browser-bot
```

## 🎮 سير العمل

1. أرسل `/start` للبوت.
2. (اختياري) اختر *🌍 الدولة*.
3. اضغط *🚀 بدء جلسة جديدة*.
4. لوحة التحكم — كل ضغطة = خطوة + لقطة شاشة.
5. اضغط *💾 حفظ وإنهاء* لتستلم:
   - `session_<id>_<ts>.py` — سكربت Python كامل (يستخدم نفس المتصفح والدولة).
   - `session_<id>_<ts>.md` — تقرير مفصّل.
   - `session_<id>_<ts>.json` — بيانات خام.

## 🧠 ملاحظات تقنية

- **Camoufox**: متصفّح خاص لكل مستخدم (الإعدادات launch-time).
  Playwright: متصفح مشترك مع contexts معزولة (أخفّ).
- لقطة شاشة *Viewport* فقط (لمحاذاة الشبكة).
- كشف كود التحقق: regex على أرقام 4-8 خانات بجوار `code/كود/تحقق`.
- السكربت المُولَّد يحتوي محرّك الكتابة البشرية كاملاً، فيتطابق الردّ
  الآلي مع تجربة المستخدم في البوت.
- البروكسي يُحفظ في السكربت — لا تشاركه دون إزالة بياناته.

## ❓ مشاكل شائعة

| المشكلة | الحل |
|---------|------|
| `Missing env vars: BOT_TOKEN` | ضع `BOT_TOKEN` في `.env` |
| البوت يستخدم Playwright بدل Camoufox | شغّل `python -m camoufox fetch` |
| الدولة بجانبها ⚪ | أضف `PROXY_<CODE>` في `.env` |
| الكتابة سريعة جداً | تأكد `HUMAN_TYPING=1` |
| تريد أخطاء كتابة | ضع `HUMAN_TYPO_RATE=0.02` |
| Camoufox لا يبدأ | تحتاج 1.5GB RAM و libdbus-glib مثبتة |
