# تحديثات البوت — شاشة أوضح + أزرار ضبط الشاشة

هذا الملف المضغوط يحتوي **ملفات التحديث فقط**. انسخها فوق نفس المسارات داخل مشروعك، ولا تحذف باقي ملفاتك.

## شنو انضاف بهذا التحديث؟

### 1) إصلاح مشكلة الصورة ما تبين كل الصفحة
- تم تغيير حجم المتصفح الافتراضي إلى **1920×1080** حتى يتصرف مثل شاشة لابتوب/ديسكتوب ويعرض مساحة أكبر.
- تم إضافة زر **🧩 ضبط الشاشة**: يضبط الشاشة تلقائياً على 1920×1080 ويصغّر الصفحة إلى 80% حتى تبين تفاصيل أكثر.
- تم إضافة زر **🖥️ شاشة واسعة** و **💻 شاشة لابتوب** للتبديل بين المقاسات.
- تم إضافة أزرار **🔍 تصغير** و **🔎 تكبير** للتحكم بزوم الصفحة بدون ما تعيد فتح الرابط.

### 2) لقطات شاشة أوضح
- زر **📸 لقطة HD** يرسل الصورة كملف حتى لا تضغطها تلگرام وتضيع التفاصيل.
- زر **🖼️ صفحة كاملة** يرسل لقطة للصفحة كاملة بالطول كملف HD.

### 3) تحسين أزرار النزول والتحريك
- أزرار النزول/الصعود لا تعتمد فقط على الصفحة الرئيسية، بل تحاول أيضاً تحريك الصناديق الداخلية القابلة للتمرير.
- أزرار اليمين/اليسار وأقصى يمين/يسار باقية ومحدثة.

### 4) حالة الصفحة أوضح
- صار يعرض X و Y بطريقة ما تنعكس بالعربي داخل تلگرام.
- صار يعرض الزوم الحالي وحجم الشاشة وحجم الصفحة.
- يعرض الصناديق الداخلية القابلة للتمرير إذا موجودة.

### 5) الموافقة من الإدمن
- المستخدم الجديد يطلب دخول.
- الإدمن يوافق مرة واحدة.
- بعدها المستخدم يقدر يستخدم البوت دائماً.

## متغيرات Railway المهمة

```env
ADMIN_IDS=ضع_ايدي_التلغرام_مالك
ACCESS_APPROVAL_REQUIRED=1
APPROVED_USERS_FILE=/data/approved_users.json
```

اختياري إذا تريد تغيّر حجم الشاشة:

```env
VIEWPORT_W=1920
VIEWPORT_H=1080
AUTO_PAGE_ZOOM=0.80
```

إذا السيرفر ضعيف وتريد مقاس أخف:

```env
VIEWPORT_W=1366
VIEWPORT_H=768
AUTO_PAGE_ZOOM=0.90
```

## طريقة الاستخدام بعد التحديث

1. افتح البوت واضغط **/start**.
2. ابدأ جلسة.
3. افتح الصفحة المطلوبة.
4. إذا الصورة ما تبين كفاية اضغط **🧩 ضبط الشاشة**.
5. إذا تريد وضوح أكثر اضغط **📸 لقطة HD**.
6. إذا تريد الصفحة كلها بالطول اضغط **🖼️ صفحة كاملة**.
