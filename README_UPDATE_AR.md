# تحديثات البوت — بدون حذف ملفاتك القديمة

هذا الملف المضغوط يحتوي **ملفات التحديث فقط**. انسخها فوق نفس المسارات داخل مشروعك القديم.

## ماذا تم تعديل؟

1. إصلاح التمرير:
   - نزول بسيط/صعود بسيط أصبح أذكى ويشتغل حتى مع الصفحات التي داخلها صندوق تمرير داخلي.
   - نزول نهاية/صعود نهاية أصبح يحاول تحريك الصفحة والعناصر الداخلية، وليس `window.scrollTo` فقط.

2. إضافة أزرار جديدة للشاشة:
   - ⬅️ تحريك يسار
   - ➡️ تحريك يمين
   - ⇤ أقصى يسار
   - أقصى يمين ⇥
   - 🧭 حالة الصفحة

3. تحسين لقطة الشاشة:
   - كل لقطة ترجع معها معلومات مختصرة: موضع X/Y، حجم الشاشة، حجم الصفحة، العنوان، والرابط.
   - هذا يساعدك تفهم هل المشكلة من الصفحة، من موضع الشاشة، أو من عرض الصفحة.

4. نظام موافقة الإدمن:
   - إذا وضعت `ADMIN_IDS`، أي شخص جديد يضغط /start راح يرسل طلب للإدمن.
   - الإدمن يضغط ✅ موافقة دائمة، وبعدها المستخدم يقدر يستخدم البوت دائماً.
   - بدون `ADMIN_IDS` يبقى البوت مثل قبل حتى لا ينقفل عليك بالخطأ.

## متغيرات اختيارية جديدة

```env
# رقمك/أرقام الإدمن، مفصولة بفارزة
ADMIN_IDS=123456789

# ملف حفظ المستخدمين الموافق عليهم
# على Railway الأفضل تخليه داخل Volume حتى يبقى دائم
APPROVED_USERS_FILE=/data/approved_users.json

# تفعيل نظام طلب الموافقة: 1 مفعّل، 0 معطّل
ACCESS_APPROVAL_REQUIRED=1

# قوة التمرير العمودي والأفقي
SCROLL_STEP_Y=650
SCROLL_STEP_X=650
```

## طريقة التركيب

1. فك الضغط.
2. انسخ مجلد `bot` الموجود داخل هذا التحديث فوق مجلد `bot` بمشروعك.
3. ارفع التغييرات إلى GitHub.
4. أعد تشغيل Railway.
5. تأكد أن `ADMIN_IDS` موجود حتى يشتغل نظام الموافقة.

> ملاحظة: لم يتم حذف أي ملف من مشروعك. هذه ملفات استبدال/إضافة فقط.
